## 💡 Como Usar Este Plano

1.  🖥️ **Utilize o Painel Web (Recomendado)**: Abra o arquivo `index.html` no seu navegador dando um duplo clique nele. Digite suas anotações nele em tempo real, salve e baixe o arquivo `.md` correspondente à semana!
2.  **Siga o Roteiro**: Utilize o arquivo `cronograma.md` para acompanhar o progresso diário/semanal. Marque os tópicos concluídos utilizando o checkbox `[x]`.
3.  **Faça Anotações Físicas**: Se preferir não usar o Painel Web, crie uma cópia do arquivo `anotacoes/semana-01.md` com o nome da semana correspondente (ex: `semana-02.md`, `semana-03.md`) e registre seus aprendizados, códigos de exemplo e dúvidas.
4.  **Consulte os Recursos**: O arquivo `recursos.md` contém o mapeamento dos PDFs, livros e bootcamps que você possui. Use-os como sua principal fonte de consulta.
5.  **Pratique**: A melhor forma de aprender programação é escrevendo código. Não se limite a ler; implemente os conceitos em projetos práticos.

> [!TIP]
> **Dica de Ouro:** A constância é mais importante do que a intensidade. Dedique um tempo focado todos os dias, utilize IA como uma ferramenta de co-pilotagem para tirar dúvidas e acelerar o seu desenvolvimento!
