# 📚 Recursos e Materiais de Estudo

Este repositório consolida as fontes de referência citadas no seu plano de estudos do PDF. Mantenha esses arquivos por perto e utilize-os ativamente para complementar seus estudos diários.

---

## Mapeamento por Semana

### 🟩 Recursos para a Semana 1: Fundamentos Essenciais
*   **Material "Formação Java Fundamentals"**:
    *   *Foco*: Sintaxe básica de Java, tipos de dados primitivos, condicionais e estruturas de repetição.
*   **Desafio "72 Horas Javanauta"**:
    *   *Foco*: Aprofundamento prático em Java estruturado e primeiros passos em Orientação a Objetos.
*   **Arquivo de Referência:** `Internacao.java`
    *   *Foco*: Analise a estrutura de classes, construtores, atributos e métodos contidos neste arquivo para entender boas práticas de escrita de código Java.

### 🟦 Recursos para a Semana 2: Java Moderno e Persistência
*   **Documentos de Referência de Banco de Dados**:
    *   *Foco*: Sintaxe SQL pura.
    *   *Exercícios recomendados*: Pratique comandos como `CREATE DATABASE`, `CREATE TABLE` e `INSERT` em ambientes como **H2 Database** (perfeito para testes locais rápidos) e **PostgreSQL**.

### 🟪 Recursos para a Semana 3: Spring Boot Core
*   **Livro PDF:** `algaworks-livro-spring-boot-v3.0.pdf`
    *   *Foco Crítico*: Leia o **Capítulo 3.10** focando no uso de `JpaRepository` e no mapeamento de entidades.
*   **Bootcamp Santander 2026 (Trilha Back-end)**:
    *   *Foco*: Seguir as aulas práticas da trilha back-end focada em Java e Spring.
*   **Guia em PDF sobre Spring MVC e Thymeleaf**:
    *   *Foco Crítico*: Estudar detalhadamente o **Capítulo 3** para compreender o fluxo de requisição/resposta das APIs RESTful.

### 🟨 Recursos para a Semana 4: Produtividade e Portfólio
*   **Conteúdos de Automação com n8n (DevQuest)**:
    *   *Foco*: Aulas e conceitos de criação de fluxos de automação modernos sem código ou com baixo código usando n8n.
*   **Projeto do Assistente Virtual**:
    *   *Foco*: Desenvolver e implementar o projeto proposto no bootcamp, integrando IA nas suas respostas.
*   **Indicação Adicional:** *Guias Gratuitos - Notion*
    *   *Foco*: Utilizar estes guias de estudo no Notion para organizar seu roadmap e revisar conteúdos extras.

## 💡 Estratégias para Estudo Eficiente de PDFs e Livros
1.  **Leitura Ativa**: Nunca leia apenas de forma passiva. Mantenha a IDE (como VS Code ou IntelliJ IDEA) aberta ao ler o livro da Algaworks e digite você mesmo os mapeamentos de entidade JPA.
2.  **Debugging**: Use o depurador da sua IDE para entender o fluxo de execução das requisições REST do Spring MVC passo a passo.
3.  **Projetos Reais**: Utilize o Git desde o primeiro dia da semana 3 para versionar suas APIs, mesmo que sejam simples CRUDs de teste.
