# 📅 Cronograma Semanal (30 Dias)

Acompanhe seu progresso semanal passo a passo. Utilize este arquivo como um checklist interativo para monitorar sua evolução ao longo dos 30 dias de foco intenso.

---

## 🟩 Semana 1: Fundamentos Essenciais (Fundamentos Sólidos)

### 📚 Recursos recomendados
- Site: https://example.com
- YouTube: https://youtube.com/channel1
*Foco: Consolidar a base de programação estruturada e o paradigma de Orientação a Objetos utilizando Java.*

### Checklist de Atividades:
- [ ] **Lógica de Programação**: Revisar fluxogramas, condicionais (`if/else`, `switch`) e estruturas de repetição (`for`, `while`, `do-while`).
- [ ] **Sintaxe Java & Tipos de Dados**: Praticar a declaração de variáveis com tipos primitivos (Inteiro, Real, Literal, Lógico) e objetos.
- [ ] **Arrays & Coleções Básicas**: Manipulação de vetores de tamanho fixo.
- [ ] **Orientação a Objetos (OO)**:
  - [ ] Criação de Classes e Objetos
  - [ ] Encapsulamento (Getters/Setters, modificadores de acesso)
  - [ ] Herança e Polimorfismo
  - [ ] Construtores e métodos especiais
- [ ] **Revisão Prática**: Ler e analisar a estrutura de classes no arquivo `Internacao.java` como exemplo de modelagem real.

## 🟦 Semana 2: Java Moderno e Persistência (Dados)

### 📚 Recursos recomendados
- Site: https://example.com
- YouTube: https://youtube.com/channel2
*Foco: Escrever código Java idiomático usando recursos modernos e integrar a aplicação a bancos de dados relacionais com SQL puro.*

### Checklist de Atividades:
- [ ] **Java Moderno**:
  - [ ] **Collections API**: Dominar o uso de `List`, `Set` e `Map` (ArrayList, HashSet, HashMap).
  - [ ] **Expressões Lambda**: Simplificar a escrita de código funcional.
  - [ ] **Streams API**: Filtrar, mapear e coletar dados com pipelines elegantes de processamento de coleções.
- [ ] **Bancos de Dados & SQL**:
  - [ ] Comandos DDL: Criar tabelas (`CREATE TABLE`), alterar estruturas.
  - [ ] Comandos DML: Inserir dados (`INSERT`), atualizar (`UPDATE`) e deletar (`DELETE`).
  - [ ] Consultas Complexas: `SELECT` utilizando filtros (`WHERE`), ordenação (`ORDER BY`) e junções se necessário.
- [ ] **Ambiente de Prática**: Configurar e praticar os comandos em bancos em memória (**H2**) e no banco físico (**PostgreSQL**).

## 🟪 Semana 3: Framework Spring Boot Core

### 📚 Recursos recomendados
- Site: https://example.com
- YouTube: https://youtube.com/channel3
*Foco: Dominar o framework Java mais utilizado no mercado corporativo, entendendo desde o fluxo web até a persistência automática de dados.*

### Checklist de Atividades:
- [ ] **Spring Core & Injeção de Dependência**:
  - [ ] Compreender o conceito de inversão de controle (IoC).
  - [ ] Utilizar as anotações `@Component`, `@Service`, `@Repository`, `@Autowired` e `@Bean`.
- [ ] **Spring Data JPA**:
  - [ ] Aprender a mapear entidades JPA (`@Entity`, `@Table`, `@Id`, `@GeneratedValue`, `@Column`).
  - [ ] Criar repositórios estendendo a interface `JpaRepository` para operações CRUD automáticas.
- [ ] **Spring MVC & APIs RESTful**:
  - [ ] Desenvolver controllers REST usando `@RestController` e `@RequestMapping`.
  - [ ] Mapear verbos HTTP (`@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`).
  - [ ] Trabalhar com transferência de dados usando padrões de requisição e resposta (JSON).
  - [ ] Estudar o fluxo de requisição/resposta (Capítulo 3 do guia em PDF sobre Spring MVC e Thymeleaf).

## 🟨 Semana 4: Produtividade, Automação e Portfólio

### 📚 Recursos recomendados
- Site: https://example.com
- YouTube: https://youtube.com/channel4
*Foco: Preparar seu portfólio para o mercado, integrando IA nas suas aplicações e automatizando fluxos de trabalho com ferramentas modernas.*

### Checklist de Atividades:
- [ ] **Versionamento de Código**:
  - [ ] Dominar comandos Git essenciais (`git init`, `git add`, `git commit`, `git push`, `git branch`).
  - [ ] Organizar seu GitHub de forma profissional, com READMEs explicativos para cada projeto.
- [ ] **Automação com n8n (DevQuest)**:
  - [ ] Entender a arquitetura de workflows baseada em nós.
  - [ ] Integrar Webhooks, APIs externas e notificações usando n8n.
- [ ] **Integração com Inteligência Artificial**:
  - [ ] Aprender a conectar suas APIs Java com serviços de IA (ex: OpenAI API ou Claude API).
  - [ ] Desenvolver o projeto do **Assistente Virtual** proposto no bootcamp.
- [ ] **Projeto Final de Portfólio**:
  - [ ] Finalizar uma API robusta com Spring Boot integrada com banco de dados, documentada com Swagger, versionada no GitHub e com automações adicionais.
